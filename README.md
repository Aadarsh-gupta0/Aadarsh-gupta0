## 👋 About Me

I'm a third-year B.Tech student at **KIIT** who sits right at the seam between **design and engineering** — I care as much about how an interface *feels* as about the architecture holding it up.

- 🎨 I design in **Figma**, then build it for real in **Flutter** and **React/Next.js**
- 🧠 Currently shipping a **student-first career discovery platform** in Flutter
- 🌱 Levelling up my backend game with **Spring Boot** and **Go**
- 🤝 Building with the community at **GDG KIIT**
- 💬 Ask me about **Flutter state management**, **MERN**, or **design systems**

<details>
<summary><b>🎯 More about how I work →</b></summary>

<br/>

I tend to start with the user, not the stack. A typical project for me looks like:

| Phase | What I actually do |
| :--- | :--- |
| **1. Frame** | Understand the real problem, sketch the flows, define scope |
| **2. Design** | Wireframe → high-fidelity UI in Figma, build a small design system |
| **3. Build** | Ship the frontend, then the API, iterating in vertical slices |
| **4. Refine** | Responsiveness, edge cases, performance, and polish |

**What I'm looking for:** internships and collaborative projects where design and engineering aren't separate departments.

</details>
